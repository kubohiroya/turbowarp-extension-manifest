Extension Manifest

責務と公開範囲

Templateから抽出した、拡張API manifestの生成・検証・serializeとgetInfo用block定義変換を共通化するlibraryです。拡張ブロックそのものは登録しません。

このページはlibraryのドキュメントです。TurboWarp拡張の独立したpaletteやブロックは提供しません。

使い方

公開済みの完全固定versionを使います。

npm install --save-exact @kubohiroya/turbowarp-extension-manifest@0.3.2
import {createExtensionManifest, serializeExtensionManifest}
  from '@kubohiroya/turbowarp-extension-manifest';

const definitions = {blocks: []};
const manifest = createExtensionManifest('myextension', definitions);
const json = serializeExtensionManifest('myextension', definitions);

API

入口責務
createExtensionManifest拡張IDとblock定義からmanifestを生成し、opcode重複とmenu参照を検証します。
serializeExtensionManifeststable key orderでmanifestをserializeします。
createTurboWarpBlockDefinitionsmanifest風block定義をScratchの型表現へ変換します。
createTurboWarpExtensionInfo呼出元が指定した拡張メタデータとblock定義からgetInfo結果を作ります。
extensionManifestPluginビルド時にextension manifestを生成するpluginです。

全ての公開型・引数はREADMEとsourceを参照してください。
